# Contributing to Student Engagement Detection

Thank you for your interest in contributing to our research repository!

## Code of Conduct & Academic Integrity
This repository contains research artifacts and ablation benchmarks accompanying the paper:
*"A Dual-Stream Temporal Transformer Framework for Student Engagement Detection in Classroom Videos"*.

## How to Contribute
1. **Fork the Repository**: Create your own copy of the repository.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Ensure Code Quality**:
   - Follow PEP 8 style standards.
   - Verify that your code adheres to linting checks:
     ```bash
     flake8 . --count --select=E9,F63,F7,F82 --show-source --statistics
     ```
4. **Submit a Pull Request (PR)**:
   - Provide a clear summary of your changes.
   - Reference any relevant issues or ablation stages.
